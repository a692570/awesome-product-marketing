# Content Angle Generator Template

> A framework for generating differentiated content angles for dev-focused and AI-era products.
> Based on the Telnyx content angle skill, extended with the FullFunnel dual-path research method and social-first validation.

## How to use this template

Work through each section. The output is not a content calendar. It is a set of angles that pass a quality gate before they become content.

## 4. Angle quality gate

For each proposed angle, answer:

| Question | Answer |
|---|---|
| Could a competitor write this? | |
| Is there a named mechanism, not just a trend? | |
| Is there proof (number, screenshot, source)? | |
| Does this connect to a buying committee pain? | |
| Is this saturated in the market? (check X, LinkedIn, HN) | |

Pass = at least one "no competitor could write this" + one proof point + not saturated.
Revise = missing proof or slightly generic.
Reject = competitor could write it or already saturated.

## 6. Social-first validation

Before investing in long-form, test the angle on social.

1. Write a LinkedIn post for the angle
2. Post it
3. Measure 48-hour engagement and save rate
4. Did it generate conversations with target accounts?
5. If yes: expand to long-form (blog, video, webinar)
6. If no: move to the next angle

Key metric: conversations with target accounts, not impressions. 20x pipeline quality improvement with 5-7x reach decline is a net win.

## 7. Slop gate (before publishing)

Reject content that:
- [ ] Could have been written without knowing your product
- [ ] Uses "AI transformation" or generic GTM language
- [ ] Makes claims without proof
- [ ] Repeats an existing asset without a refresh reason
- [ ] Sounds like it could be from any vendor in your space
